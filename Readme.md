
## OMNIS : Optimized Multi-orientation Nonlinear Inversion of Susceptibility
Framework for Multiorientation Quantitative Susceptibility Mapping Methods

## Dataset

Original RC2 simulated framework data and code link:
https://doi.org/10.34973/m20r-jt17

Details of extending to multiorientation settings is given in: 
Data_generation.m 

Sample multi orientation simulated dataset generated in this paper can be downloaded from: 
https://indianinstituteofscience-my.sharepoint.com/:f:/g/personal/sejalm_iisc_ac_in/IgCTibTwQf6gS4yJry3u-ZVNAb51KzMTsHM0pACAsKjqKL0

In vivo 2016 QSM Challenge Dataset used in this paper:
http://qsm.neuroimaging.at

## OMNIS Framework Code

THe file main.m compares COSMOS, NDI and OMNIS. It also calculates ROI Error along with NRMSE , PSNR, SSIM and HFEN.

```md
 main.m
```
